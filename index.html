Question Commons reads question files from Canvas, Moodle, Blackboard, Kahoot, Blooket, Quizlet and more into one versioned Question Bank format, so any tool can take a teacher's questions in.

Reads the files teachers' tools write

Each format is one tool's own layout: a file it exports, or a syntax it defines and imports. A file is first set into its shape, so an Excel workbook and a CSV are the same table and a Word document is text, then read by every format of that shape.

How it reads

Never changes a question

A question comes in exactly as its file meant it, or it's left out with an issue saying where and why.

Keeps every question type

Multiple choice and answer, true/false, matching, fill in the blank, short answer, numeric and ordering.

Rules, not AI

The same file always gives the same result. Nothing is sent anywhere. Runs in the browser, Node and Bun.

Says where it came from

Every bank records its format and file, and every question its line in that file.

The spec

A Question Bank is plain JSON: a name, its questions, and where they came from. It's described by a versioned JSON Schema, and every bank names the version it follows.
