Every question bank.
One open spec.

Teachers' questions are scattered across Canvas, Moodle, Blackboard, Kahoot, Blooket and Quizlet, each in its own file format. Question Commons reads all of them into one unified, versioned Question Bank, so any tool can take a teacher's questions in.

Principles

A teacher's question is their work. The parser's job is to carry it, not reinterpret it.

Never changes a question

A question comes in exactly as its file meant it, or it's left out with an Import Issue that says where and why. Nothing is quietly turned into something else to make it fit.

Keeps every question type

Multiple choice, multiple answer, true/false, matching, fill in the blank, short answer, numeric and ordering. Each app decides what it can use; the spec never throws anything away for it.

Rules, not AI

Every format is read with fixed rules. The same file always gives the same result, nothing is sent anywhere, and it runs in the browser, Node or Bun.

Says where it came from

Every bank records the format and file it was read from, and every question its line and place in that file, so anyone can trace it back.

The spec

A Question Bank is plain JSON: a name, its questions, and where they came from. It's described by a versioned JSON Schema, and every bank names the version it follows.

Schema
/schema/question-bank-1.0.0.schema.json
Version
1.0.0, bumped in its major part only for a breaking change
Pictures
carried as the file had them, beside the banks, named from rich text
Extras
facts only one tool's files carry, kept by name and never acted on
app.tsTypeScript
import { readQuestionFile, plainText } from '@question-commons/parser'

const file = input.files[0]
const reading = await readQuestionFile({
  name: file.name,
  bytes: new Uint8Array(await file.arrayBuffer()),
})

reading.format     // 'kahoot'
reading.banks      // QuestionBank[]
reading.pictures   // { [key]: { bytes, mimeType } }
reading.candidates // other formats it could be read as

for (const issue of reading.issues) {
  // what was left out, where, and why
  console.log(issue.code, issue.line, issue.message)
}
